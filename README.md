# FocusFlow — Pomodoro + Tasks (No Database)

A lightweight, front‑end only Pomodoro timer with task tracking and weekly stats.  
All data is saved in your browser using `localStorage`. No backend, no login.

## Features
- Pomodoro timer: focus, short break, long break, auto‑continue
- Custom durations & intervals
- Task list with tags, due dates, search, filters
- Weekly focus minutes chart (vanilla Canvas)
- Export/Import JSON (backup/restore)
- Works offline (simple static files)

## How to run
- Just open `index.html` in your browser (double‑click it).
- Or use a simple server (optional): `npx serve .` then open the shown URL.

## Deploy (free)
- Push to a GitHub repo → Settings → Pages → Deploy from branch → `/ (root)` → Save.  
  Your site will be live at `https://<your-username>.github.io/<repo-name>/`.
